# Institutional Readiness Framework (IRF) Playbook

An interactive playbook and diagnostic engine designed for school leaders, system designers, and educational change-makers. 

The **Institutional Readiness Framework (IRF)** helps leaders evaluate and structure initiatives by looking beyond simple "buy-in" or compliance, diagnosing three key vectors of change readiness across six dimensions:
1. **Ability**: Do we have the capacity, tools, and time?
2. **Desire**: Do people see the value and want to do it?
3. **Obligation**: Is there a real mandate or expectation?

## Features

- **Interactive Diagnostic Engine**: Score your organization across six core dimensions to visualize readiness gaps.
- **Dynamic Scenarios**: Load predefined school scenario templates (e.g., policy implementation, tool rollouts) to see common patterns of failure and success.
- **Visual Analytics**: Interactive spider/radar charts displaying vector alignment (Ability vs. Desire vs. Obligation).
- **Sequenced Action Path**: Actionable recommendations tailored to transition your initiative from inertia to peak agency.

## Technical Details

The project is built using:
- **HTML5**: Semantic layout.
- **CSS3 (Vanilla)**: Modern dark-theme glassmorphism interface with subtle micro-animations.
- **Vanilla JavaScript**: Interactive calculations, scenario switching, and logic.
- **Chart.js**: Render data visualization for organization profiles.

## Getting Started

To run the playbook locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser, or use a local static server like Live Server / `python3 -m http.server`.
